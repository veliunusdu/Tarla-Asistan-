Yerel Docker adresi: http://localhost:8100 · API öneki: /api/v1

Kimlik doğrulama: Korunan uçlarda Authorization: Bearer <access_token>. Roller FARMER ve AGRONOMIST.

Çevrimdışı güvenlik: Faaliyet ve vaka akışlarındaki client_operation_id tekrar gönderilen isteğin yeni kayıt üretmesini engeller.

Temel akış

  1. POST /api/v1/auth/request-otp ile kod iste.
  2. POST /api/v1/auth/verify-otp ile token al.
  3. Korunan isteklere Bearer token ekle.
  4. Süre dolunca refresh tokenı bir kez kullanarak oturumu döndür.
