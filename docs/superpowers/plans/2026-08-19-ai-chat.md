# AI Chat Endpoint Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add the authenticated `/api/v1/ai/chat` endpoint with JSON and multipart request support, strict photo/history validation, and a stable mobile response contract.

**Architecture:** Add a focused `ai_chat` router and schemas. Normalize JSON and multipart requests into one internal request model, then call an injectable provider interface. Use a deterministic local provider until a real AI integration is configured.

**Tech Stack:** FastAPI, Pydantic v2, Starlette `UploadFile`, pytest, existing bearer authentication and router prefix conventions.

**Spec:** `docs/superpowers/specs/2026-08-19-ai-chat-design.md`

## Global Constraints

- Endpoint path is `/api/v1/ai/chat` under the existing API prefix.
- Photo uploads are JPEG/PNG only and limited to 5 MiB by streamed bytes.
- Success response is `{reply: string, conversation_id: string}`.
- Provider credentials and external AI calls are out of scope for this task.
